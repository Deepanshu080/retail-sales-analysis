# Retail Sales Analysis Using Python

## Project Overview
This project analyzes retail sales data using Python to identify sales trends, customer spending patterns, and product category performance.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Project Workflow
1. Loaded the retail sales dataset using Pandas.
2. Explored the dataset using summary statistics.
3. Checked for missing values and duplicate records.
4. Validated total amounts against quantity and price per unit.
5. Analyzed sales by product category, gender, and age group.
6. Analyzed monthly sales trends.
7. Created visualizations, including bar charts, a line chart, a box plot, and a correlation heatmap.
8. Exported the processed dataset to CSV.

## Key Analysis Areas
- Total revenue and average transaction value
- Product category performance
- Gender-wise sales and average spending
- Age-group sales patterns
- Monthly sales trends
- Correlations between numerical variables

## Dataset
The project uses a retail sales dataset containing transaction details, customer demographics, product categories, quantities, unit prices, and total amounts.

## Project Outcome
The analysis demonstrates practical use of Python for data cleaning, exploratory data analysis, aggregation, and visualization.
